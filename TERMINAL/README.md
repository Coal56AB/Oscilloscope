# Oscill Terminal

Приложение для подключения ПК к осциллографу через USB–UART.

- терминал Linux с вводом и выводом в одном окне;
- управление Linux и монтирование SD;
- прямые настройки каналов, развёртки и триггера;
- графики CH1/CH2 с чтением текущего окна через заданную паузу;
- дерево каталогов SD-карты в осциллографе и скачивание файлов;
- сохранение считанного окна в CSV;
- обновление прошивки по UART с проверкой и прогрессом.

Windows-приложение: `output/OscillTerminal.exe`. Исходники используют Python 3.7.9 и PySide2.

Подключение, сборка и устройство приложения описаны в [документации](../docs/TERMINAL.md).
