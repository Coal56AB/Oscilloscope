# Работа с прибором

Управление экраном, кнопками и энкодерами описано в [README интерфейса](../ZYNQ7020/gui/README.md). Развёртка задаёт видимый участок сигнала, глубина — длину записи; в STOP масштаб и положение меняются по сохранённым отсчётам. Для внешнего сигнала отключите DEBUG → SIMULATION. BMP и CSV сохраняются и открываются через меню прибора.

Последние настройки сохраняются автоматически. MENU → SETUP → PRESETS содержит пять слотов, STARTUP выбирает последние настройки или пресет для включения. В CALIBRATE канала доступны ZERO, NOISE и FREQUENCY RESPONSE: для нуля и собственного шума вход щупа замыкается на его землю, для АЧХ нужен внешний источник. Подробности — [настройки](agents/SETTINGS.md) и [калибровка](agents/CHANNEL_RESPONSE.md).

Для связи с ПК откройте `TERMINAL/output/OscillTerminal.exe`, подключите USB–UART прибора и выберите COM-порт с текущей скоростью консоли. При включении используется 1 000 000 бод, 8N1, без управления потоком. Терминал меняет настройки, получает осциллограмму и работает с файлами SD; его [инструкция](agents/TERMINAL.md) содержит команды сборки и порядок подключения.
