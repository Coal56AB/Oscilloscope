# Устройство осциллографа

Zynq объединяет ПЛИС для приёма и обработки сигнала с ARM под Linux, где работают приложение и отрисовка экрана. STM32 обслуживает кнопки, энкодеры и переключение входных диапазонов. Основной экран подключён по HDMI, сенсор — по USB.

Исходники Zynq находятся в `ZYNQ7020/`, панели — в `STM32/`, платы и корпуса — в субмодуле `PCB/`. Подробное разделение модулей и интерфейсов приведено в [документе для разработки](agents/ARCHITECTURE.md).
