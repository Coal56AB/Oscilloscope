# Проверки проекта

Программные тесты проверяют обработку сигнала, управление, форматы и взаимодействие модулей. Отдельные проверки на приборе подтверждают аппаратный захват, работу экрана, панели и обновление прошивки; успешная компиляция не заменяет такой проверки.

Условия, результаты и границы выполненных проверок собраны в [рабочем журнале](agents/TESTING.md). Команды сборки и запуска отдельных этапов находятся в [инструкции разработчика](agents/BUILD.md).
