# Плата ZYNQ MINI rev B

В приборе используется модуль с Zynq XC7Z020. Оригинальная схема платы находится [рядом с этим описанием](ZYNQ_MINI_REVB%20Schematic.pdf); она служит источником для подключения питания, памяти и периферии.

Карта соединений и аппаратные ограничения приведены в [аудите платы](../agents/zynq7020/BOARD.md). При изменении подключения следует сверяться с оригинальной схемой и фактической установленной платой.
