# Захват сигнала

Прибор получает два канала АЦП через ПЛИС и передаёт записи приложению Linux. Развёртка определяет видимый участок сигнала, глубина — длину сохранённой записи. В STOP масштаб и положение меняются по сохранённым отсчётам.

Для измерения внешнего сигнала отключите DEBUG → SIMULATION: этот режим подставляет демонстрационный сигнал после реального захвата. Калибровка нуля и шума доступна через CALIBRATE канала; подробности устройства захвата — в [техническом описании](agents/ADC_CAPTURE.md).
