# Калибровка амплитудно-частотной характеристики

Удерживайте кнопку CH1 или CH2 и выберите CALIBRATE. Откроется график АЧХ
выбранного канала. START запускает набор точек; RUN или короткое нажатие FUNC
останавливает и возобновляет его. MENU открывает управление этим режимом.
EXIT CALIBRATION возвращает обычный экран.

Подайте синус и меняйте его частоту, сохраняя амплитуду на входе прибора.
Первая принятая точка задаёт 0 дБ. Каждая следующая показывает подъём или спад
относительно неё; повторные измерения близкой частоты уточняют ту же точку.
В начале график пуст. Прибор добавляет точки по мере получения пригодных записей.
STOP сохраняет кривую, CLEAR POINTS удаляет её для нового прохода.

Выберите развёртку, на которой помещается несколько периодов входного сигнала.
Если точек пока нет, проверьте TIME и амплитуду: перегруженный вход, шум без
выраженного тона и частота ниже разрешения текущего FFT не принимаются.
В режиме калибровки частота определяется по основному спектральному пику;
используется окно Ханна и уточнение положения пика по соседним значениям.
Изменение амплитуды самого источника тоже попадёт в измеренную АЧХ.

После набора хотя бы двух частот можно включить AMPLITUDE CORRECTION.
Коррекция применяется к кривой, её измерениям и FFT в пределах измеренного
диапазона; за его пределами усиление остаётся единичным. Между точками
используется интерполяция в логарифмическом масштабе частоты. Предельная
поправка — ±24 дБ. Подъём ослабленной полосы усиливает и находящийся в ней шум.
Во время набора АЧХ коррекция обходится, чтобы измерять исходный тракт.

Это относительная амплитудная калибровка. Она не измеряет фазу и не заменяет
калибровку абсолютного напряжения. Для каждого канала сохраняется своя кривая;
измеренные кривые общие для пресетов, а включение коррекции входит в пресет.

## Проверка в SIMULATION

При включённой SIMULATION режим сам перебирает 13 частот от 100 Гц до 1 МГц.
Для CH1 моделируется ФНЧ с частотой среза 100 кГц, для CH2 — 300 кГц.
На плате измерение проходит через обычный генератор отсчётов и обработчик захвата;
настольный симулятор использует тот же закон ослабления. После набора кривой
модель канала сохраняет это ослабление, и включение коррекции позволяет увидеть
его компенсацию на обычном сигнале генератора.

Кривые SIMULATION хранятся отдельно от реальных кривых обоих каналов.
Переключение SIMULATION останавливает текущий набор; тестовый проход не заменяет
измеренную характеристику. Обе пары кривых сохраняются при выключении прибора.

## Обработка

Канал хранит до 96 частотных точек; попадания в пределах 2% уточняют существующую
точку. Калибровка принимает выраженный тон, содержащий не менее трёх периодов
на интервале FFT, ниже 0,4 частоты отсчётов и без насыщения кодов АЦП.

Коррекция выполняется обработчиком захвата над производной копией всей записи.
Данные дополняются отражением концов, преобразуются общим radix-two FFT,
умножаются на обратную амплитудную характеристику и возвращаются обратным FFT.
Исходная запись и источник триггера сохраняются; STOP и ZOOM пересчитываются
из той же записи. Затем применяется выбранный FILTER. У интервалов Peak Detect
неизвестно время экстремумов, поэтому они не проходят через частотную коррекцию
и не накладываются поверх исправленного следа.
