# Калибровка каналов

Удерживайте CH1 или CH2 и откройте CALIBRATE. Для ZERO замкните вход щупа на его землю и выберите MEASURE ZERO; прибор измерит смещение на рабочих диапазонах. С тем же подключением NOISE → MEASURE NOISE измеряет собственный шум для автоматического сглаживания.

FREQUENCY RESPONSE предназначен для измерения и коррекции АЧХ канала с внешним источником сигнала. Подключение, порядок прохода и действия сброса описаны в [подробной инструкции](agents/CHANNEL_RESPONSE.md).
