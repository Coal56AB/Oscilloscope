# Oscill Terminal

ПК-приложение находится в `TERMINAL/output/OscillTerminal.exe`. Подключите USB–UART прибора, выберите COM-порт и текущую скорость консоли, затем нажмите «Подключиться». При включении прибор использует 1 000 000 бод, 8N1, без управления потоком.

Приложение позволяет читать и менять настройки, получать осциллограмму, работать с файлами SD и обновлять прошивку. Порядок работы и сборки приведён в [подробной инструкции](agents/TERMINAL.md), обновление — [здесь](UART_UPDATE.md).
