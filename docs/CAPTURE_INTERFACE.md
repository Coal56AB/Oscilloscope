# Данные захвата

Запись содержит исходные отсчёты двух каналов, частоту выборки и положение триггера. Экранная кривая строится из этой записи; изменение масштаба в STOP позволяет рассматривать сохранённый сигнал.

Программный интерфейс драйвера, аппаратные регистры и форматы данных описаны в [справочнике для разработки](agents/CAPTURE_INTERFACE.md).
