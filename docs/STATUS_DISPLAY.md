# Служебный OLED

Задний OLED показывает состояние прибора, связь и температуры независимо от основного экрана. Кнопка K1 переключает страницы по кругу; удержание не вызывает повторных переключений.

При загрузке OLED показывает текущий этап, при стартовой ошибке — причину. После запуска доступна обычная последовательность страниц. Состав страниц и источники показаний описаны в [подробном документе](agents/STATUS_DISPLAY.md).
