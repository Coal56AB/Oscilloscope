# Устройство и подключение

Zynq XC7Z020 принимает данные двух каналов АЦП и выполняет аппаратный триггер; приложение Linux обслуживает основной экран и связь с ПК. Экран подключён по HDMI, сенсор — по PS USB Host. STM32F103RCT6 обслуживает кнопки, энкодеры и входные диапазоны, обмениваясь состоянием с Zynq по UART.

Схемы и плата находятся в [`PCB/`](../PCB/), оригинальная схема модуля Zynq — в [`docs/zynq7020/`](zynq7020/). Распиновка и ограничения приведены в [аудите модуля](agents/zynq7020/BOARD.md) и [описании STM32](agents/STM32.md). Разделение программных модулей — в [архитектуре](agents/ARCHITECTURE.md).

Задний OLED показывает состояние, связь и температуры; кнопка K1 переключает страницы. Во время загрузки он показывает текущий этап, при стартовой ошибке — причину. Состав страниц приведён в [описании OLED](agents/STATUS_DISPLAY.md).
