# Контроллер панели

STM32F103RCT6 обслуживает кнопки и энкодеры, переключает входные диапазоны и обменивается состоянием с Zynq через UART. Исходники прошивки находятся в `STM32/`, конфигурация периферии — в `oscill_controls.ioc`, проект Keil — в `MDK-ARM/`.

Распиновка, настройка CubeMX, сборка и автономная отладка описаны в [документе разработчика](agents/STM32.md). Порядок записи — в [инструкции по прошивке](agents/FLASHING.md#stm32).
