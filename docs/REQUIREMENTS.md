# Требования к прибору

Цель проекта — автономный осциллограф на Zynq-7020 с Linux, HDMI-экраном, USB-сенсором и панелью STM32. Прибор должен получать два канала через ПЛИС, предоставлять триггер и измерения, сохранять осциллограммы и снимки на съёмный носитель.

Существующий интерфейс на C, поддержка Windows и Linux и форматы BMP/CSV сохраняются. Полное исходное ТЗ и требования к разработке находятся в [материалах для агентов](agents/REQUIREMENTS.md).
