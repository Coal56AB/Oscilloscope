# Сборка

Полная сборка Zynq запускается из корня репозитория командой `./ZYNQ7020/linux/build.ps1` после подготовки окружения. Результат находится в `ZYNQ7020/output/linux/`: `BOOT.BIN`, `image.bin`, `qspi.bin` и `fsbl.elf`.

GUI также собирается отдельно для Windows и Linux, панель STM32 — проектом Keil из `STM32/MDK-ARM/`. Подготовка окружения и команды отдельных этапов приведены в [инструкции разработчика](agents/BUILD.md).
