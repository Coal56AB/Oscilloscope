# Настройки и пресеты

Прибор автоматически сохраняет последние настройки: включение, диапазон, положение,
связь и щуп каждого канала, развёртку и длину записи, триггер, курсоры,
измерения и их расположение, PROCESSING, DEBUG, вид экрана и скорость UART.
После запуска восстанавливаются также RUN/STOP и назначения энкодеров.

В MENU → SETUP → PRESETS доступны пять независимых пресетов. Откройте PRESET 1–5:
SAVE CURRENT SETTINGS сохраняет текущие настройки в выбранный слот,
LOAD SETTINGS загружает их. EMPTY означает, что слот ещё не заполнен.
Сообщение PRESET SAVED подтверждает завершение записи.

STARTUP выбирает состояние при следующем включении: LAST восстанавливает
последние настройки, 1–5 — выбранный пресет. Если этот слот пуст, используется
последнее состояние. Загрузка пресета во время работы не меняет выбор STARTUP.

Настройки сохраняются без отдельной команды. Остановленная запись сигнала
в пресет не входит: после запуска в STOP прибор получает одну новую запись
с восстановленными параметрами. Просмотр сохранённого CSV не заменяет
настройки текущего измерения.

## Управление энкодерами

Вне меню FUNC перемещает выбранный курсор. Поворот по часовой стрелке
в режиме VERTICAL поднимает курсор, в режиме TIME перемещает его вправо.

MENU/BACK открывает меню. FUNC вращением выбирает строку, нажатием выполняет
действие. В строках с видимыми вариантами каждое нажатие выбирает следующий
по кругу. В строках с «− / +» нажатие включает EDIT, вращение меняет значение,
повторное нажатие применяет его. MENU/BACK отменяет незавершённое редактирование.
На границах числового диапазона значение останавливается.
Меню также управляется энкодером над вызвавшей его кнопкой: CH1/CH2 — свои
каналы и их калибровка, TIME — курсоры, TRIGGER — триггер. Вращение выбирает
строку или меняет значение EDIT, нажатие применяет, удержание возвращает назад.
В открытом меню канала его энкодер не переключает реле диапазона вне EDIT.
При ожидании триггера зелёный RUN меняется на жёлтый HOLD; нажатие останавливает
захват так же, как в RUN.
RUN появляется после принятия захвата, до обработки и отрисовки новой кривой.
Он сохраняется до вывода этой записи на дисплей, затем возвращается HOLD до
следующего срабатывания триггера. В AUTO захват показывает RUN постоянно.
Недоступные строки и варианты серые и не реагируют на нажатие. FUNC пропускает
недоступные строки и варианты: пустой пресет нельзя загрузить или выбрать для
STARTUP; коррекция АЧХ доступна после измерения хотя бы двух частот.

Все разделы доступны с панели. Настройки каналов, триггера и курсоров открываются
удержанием соответствующей кнопки; остальные — через MENU. Масштаб и положение
времени меняются энкодером TIME; отдельного TIME в SETUP нет.
Длина записи находится в PROCESSING → RECORD LENGTH.
Скорость UART находится в SETUP → PC CONNECTION; она и частота генератора
редактируются через EDIT. SETUP — первый пункт главного меню.
В DISPLAY доступны сетка, GRID BRIGHTNESS (0–10) и выбор шрифта PIXEL/INTER.
Яркость 5 сохраняет исходный контраст; 0 убирает сетку. Значение сохраняется
в последних настройках и пресетах независимо от переключателя GRID.
DISPLAY → LAYOUT позволяет показать или скрыть измерения, выбрать ROW/COLUMN,
переместить измерения и меню, изменить высоту разделённых окон. Числовые параметры
редактируются через EDIT; высота доступна при включённых FFT или ZOOM.
FILES содержит сохранение BMP, CSV или обоих файлов и переходы по открытым CSV.
В списке файлов удержание FUNC открывает подтверждение удаления; вращение выбирает
CANCEL/DELETE, нажатие подтверждает. При просмотре BMP нажатие FUNC открывает
следующий файл, удержание — предыдущий; MENU или RUN закрывает просмотр.
CALIBRATE в настройках канала открывает [калибровку АЧХ](CHANNEL_RESPONSE.md).
В MEASURE строка HIDE доступна тем же вращением и нажатием FUNC, что и список
измерений; она полностью скрывает таблицу без удаления её состава и положения.
Повторное открытие — MENU → MEASUREMENTS → SHOW или DISPLAY → LAYOUT → MEASUREMENTS.
Ширина столбцов
задаётся составом измерений и шрифтом, а не текущими цифрами или единицами.

PERSISTENCE в PROCESSING оставляет на экране 1, 4 или 8 последних захватов.
Старые кривые тускнеют; текущая рисуется обычной яркостью. Это послесвечение,
а не усреднение или фильтрация. При изменении геометрии сигнала история очищается,
чтобы следы старого масштаба не смешивались с новым.

## Хранение и реализация

На Zynq файл `/var/lib/oscill/setup.conf` расположен в JFFS2 существующего раздела
QSPI `settings` размером 1 МиБ. S97oscill-settings монтирует раздел до запуска GUI;
обычное обновление BOOT/FIT его не затрагивает. При недоступном разделе служба
запускает GUI без сохранения и пишет причину в журнал.
Составной `qspi.bin` заканчивается перед этим разделом и также не содержит
пользовательских настроек.

Настольная версия использует `oscill-settings.conf` рядом с исполняемым файлом.
Параметр `--settings-file PATH` задаёт другой файл, `--no-settings` отключает
загрузку и запись, например для независимой проверки интерфейса.

`demo_settings` определяет снимок подтверждённых пользовательских параметров и
проверяет их границы. `settings_session` хранит последнее состояние и пять
пресетов, кодирует документ с версией и проверяет его целиком до применения.
`settings_store` выполняет файловые операции отдельным потоком: объединяет
изменения после 500 мс покоя, при непрерывном вращении пишет не реже раза в 2 с.
Явное сохранение пресета и штатное закрытие не ждут этого интервала.
Запись идёт во временный файл с синхронизацией, затем атомарно заменяет основной.
Если существующий документ повреждён, недоступен для чтения или записан более
новой неподдерживаемой версией, GUI сообщает SETTINGS LOAD FAILED и оставляет
файл без изменений. В этом запуске автосохранение и SAVE пресетов недоступны:
заводские значения не заменяют прежние настройки. Отсутствующий файл создаётся
при первом сохранении. При обновлении используются настройки, прочитанные из
постоянного раздела; проверочные снимки состояния поверх него не восстанавливаются.

Релейные диапазоны после загрузки передаются STM32 абсолютными командами.
Для включённых каналов захват ждёт подтверждения диапазона; ожидание OFF
не останавливает второй канал. Старое сообщение панели не заменяет
восстановленный диапазон. Исходные отсчёты, история экрана, телеметрия и
неподтверждённые значения EDIT в документ не входят.

Документ версии 6 добавляет яркость сетки; при чтении версий 1–5 она равна 5.
Начиная с версии 5 документ независимо сохраняет ноль, шум и их коэффициенты преобразования
для трёх ступеней каждого реального и имитируемого канала. Версии 1–4 читаются;
результаты версий 3 и 4 переносятся на соответствующую ступень по коэффициенту,
а в версиях 1 и 2 они не измерены.
