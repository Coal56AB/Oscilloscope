# Проверка при включении

Перед открытием осциллографа прибор проверяет готовность оборудования. Этап виден на основном экране и служебном OLED. При отказе показываются STARTUP FAILED и причина; проверка повторяется автоматически, после успешного завершения открывается осциллограф.

Отсутствие USB-сенсора не мешает запуску: прибор поддерживает подключение сенсора во время работы. Состав аппаратной проверки и её границы приведены в [техническом описании](agents/STARTUP_CHECKS.md).
