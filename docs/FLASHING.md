# Обновление прошивки

Для обновления Zynq подключите USB–UART P1 и откройте вкладку «Прошивка» в Oscill Terminal. Выберите каталог с `BOOT.BIN` и `image.bin`, нажмите «Перепрошить прибор» и дождитесь завершения и перезагрузки. Порядок работы — в [описании UART-обновления](UART_UPDATE.md).

Для записи через Xilinx SDK и восстановления загрузки используются файлы из `ZYNQ7020/output/linux/`. Способы записи Zynq и STM32 приведены в [подробной инструкции](agents/FLASHING.md).
