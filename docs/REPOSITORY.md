# Каталоги проекта

`ZYNQ7020/` содержит приложение, ПЛИС и Linux; `STM32/` — прошивку панели. `PCB/` является отдельным субмодулем с платой и корпусом. `TERMINAL/` содержит приложение для подключения к прибору с ПК.

В корне `docs/` находятся краткие описания, в `docs/agents/` — подробности реализации и рабочие материалы разработки. Исходные схемы и даташиты остаются в тематических каталогах. Подробная карта исходников — [здесь](agents/REPOSITORY.md).
