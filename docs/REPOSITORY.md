# Организация репозитория

```text
Oscill/
├── ZYNQ7020/
│   ├── gui/          приложение C, WinAPI/SDL и переносимые тесты
│   ├── fpga/         RTL, HDMI, аппаратный проект и симуляция Vivado
│   ├── standalone/   тест DDR/HDMI и общая настройка видео для FSBL
│   └── linux/        br2-external, rootfs, PS DTS и ARM toolchain
├── STM32/            CubeMX/Keil для STM32F103RCT6 и тесты панели
│   ├── Core/         приложение и генерируемая периферия
│   ├── Drivers/      HAL/CMSIS
│   └── MDK-ARM/      проект Keil и startup
├── PCB/              субмодуль OscilPCB, Altium и изображения платы
└── docs/             требования, разработка и проверка устройства
```

## GUI и PCB

GUI перенесён из субмодуля `GUI` в обычный каталог `ZYNQ7020/gui`: приложение, Linux-пакет и PL ABI развиваются в одном проекте устройства. Исходные изображения, шрифты, Windows/Linux frontend, тесты и Tinker Board сохранены. PCB остаётся субмодулем: у него отдельные исходники Altium и история. Изменений внутри PCB нет; путь сохранён как `PCB`.

Перед переносом рабочие деревья были чистыми. Состояние исходного GUI — `16c10c6`; исходный главный проект — `9a13e23`. Сохранены:

- `.git/migration/GUI/` — исходные файлы до изменений;
- `.git/migration/oscilgui.bundle` — все доступные Git refs GUI;
- `refs/archive/oscilgui` — импортированная история GUI в главном Git;
- `.git/modules/GUI/` — исходная Git-база субмодуля;
- `.git/migration/gui-git-pointer` — прежний файл связи рабочего дерева с Git-базой.

Приложение и сборка не зависят от этих локальных резервных файлов. Bundle и архивный ref не заменяют включение истории в публикуемую ветку: обычный push главной ветки сам по себе их не отправит.

## Сохранение истории при фиксации переноса

После проверки и отдельного коммита новых путей историю можно присоединить merge-коммитом без изменения текущих файлов:

```sh
git merge -s ours --no-commit --allow-unrelated-histories refs/archive/oscilgui
git commit
```

Заголовок и содержательное описание коммита писать по-русски. Перед merge рабочее дерево должно быть чистым. В старых коммитах пути GUI остаются исходными; текущие исходники находятся под `ZYNQ7020/gui`. Это сохраняет исходные SHA без переписывания истории. Перед публикацией проверить родителей merge-коммита и `git log --all`.

## Восстановление исходного GUI

Без затрагивания текущей разработки можно восстановить полноценный исходный репозиторий в заранее выбранный пустой каталог:

```sh
git clone .git/migration/oscilgui.bundle /absolute/recovery/OscilGUI
```

Копия `.git/migration/GUI` служит резервом файлов, а не самостоятельным рабочим Git-деревом: относительный `.git` указатель в ней больше не соответствует расположению. Для возврата структуры сначала сохранить текущие изменения отдельным bundle/патчем и копией новых файлов, затем восстановить исходный gitlink из `9a13e23` и файлы из восстановленного GUI. Не применять `reset --hard`/`clean` к незакоммиченному результату.
