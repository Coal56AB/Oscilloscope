# Настройки и пресеты

Прибор автоматически сохраняет последние настройки каналов, развёртки, записи, триггера и вида экрана. В MENU → SETUP → PRESETS доступны пять слотов: SAVE CURRENT SETTINGS сохраняет настройки, LOAD SETTINGS применяет выбранный пресет.

STARTUP выбирает восстановление последних настроек или пресета при включении. Пресет содержит настройки, а не остановленную запись сигнала. Управление энкодерами и полный состав настроек описаны в [подробной инструкции](agents/SETTINGS.md).
