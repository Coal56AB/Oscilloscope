# Решения по проекту

Прибор состоит из устройства Zynq с Linux и ПЛИС, контроллера панели STM32 и отдельного проекта платы и корпуса. Приложение сохраняет общий интерфейс для Windows и Linux; схемы и аппаратные исходники лежат рядом с соответствующими проектами.

История технических решений, их основания и ограничения собраны в [материалах для разработки](agents/DECISIONS.md). Это рабочая история проекта, а не руководство пользователя.
