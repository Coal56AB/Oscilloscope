# Обновление через Oscill Terminal

Подключите ПК к USB–UART P1 и дождитесь входа в Linux. Во вкладке «Прошивка» выберите каталог с `BOOT.BIN` и `image.bin` и нажмите «Перепрошить прибор». Ход обновления отображается на ПК и основном экране; после завершения прибор перезагрузится.

Передача и запись проверяются автоматически. Для обновления используются отдельные `BOOT.BIN` и `image.bin`; составной `qspi.bin` предназначен для другого способа записи. Технические подробности и восстановление при старой прошивке — в [полной инструкции](agents/UART_UPDATE.md).
