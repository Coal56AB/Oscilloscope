# Первый запуск

Подключите HDMI и USB–UART P1. Начальная скорость консоли — 1 000 000 бод, 8N1, без управления потоком. После загрузки Linux приложение запускается автоматически; при стартовой ошибке экран показывает её причину и повторяет проверку.

Для первоначальной проверки DDR и HDMI предусмотрена диагностическая прошивка с запуском из TF1. Порядок подготовки и выбора загрузки — в [подробной инструкции](agents/BRINGUP.md), обновление рабочего прибора — в [описании прошивки](FLASHING.md).
