OscilGUI для ASUS Tinker Board
================================

Интерфейс двухканального осциллографа с демосигналами, измерениями,
курсорами, FFT и сохранением BMP/CSV.

Пакет содержит версии для Tinker Board / Tinker Board S (ARM32) и ARM64.
Нужна графическая среда TinkerOS/Debian с X11. Компилятор и SDL2 на плате
не требуются. Приложение открывается на весь экран.

Установка с USB-флешки
----------------------

1. Распакуйте ZIP на флешку FAT32 или exFAT.
2. Загрузите Tinker Board и подключите флешку.
3. Откройте папку и запустите START.desktop; при запросе выберите
   «Доверять и запустить».

Сборка, параметры запуска и диагностика описаны в BUILDING.md.
